### 93. Restore IP Addresses

A valid IP address consists of exactly four integers separated by single dots. Each integer is between 0 and 255 (inclusive) and cannot have leading zeros.

For example, "0.1.2.201" and "192.168.1.1" are valid IP addresses, but "0.011.255.245", "192.168.1.312" and "192.168@1.1" are invalid IP addresses.
Given a string s containing only digits, return all possible valid IP addresses that can be formed by inserting dots into s. You are not allowed to reorder or remove any digits in s. You may return the valid IP addresses in any order.

 

Example 1:

Input: s = "25525511135"
Output: ["255.255.11.135","255.255.111.35"]
Example 2:

Input: s = "0000"
Output: ["0.0.0.0"]
Example 3:

Input: s = "101023"
Output: ["1.0.10.23","1.0.102.3","10.1.0.23","10.10.2.3","101.0.2.3"]
 

Constraints:

1 <= s.length <= 20
s consists of digits only.

##### Correct solution

````cpp
class Solution {
public:
    vector<string> recursiveIpAddressSplitting(string s, int segments_remaining) {
        if (segments_remaining == 0) return s.empty() ? vector<string>{""} : vector<string>{};
        if (s.empty()) return {};
        
        vector<string> result;
        int running_num = 0;
        for (int i = 0; i < min((int)s.length(), 3); ++i) {
            running_num = running_num * 10 + (s[i] - '0');
            if (running_num > 255) break;
            
            auto substrings = recursiveIpAddressSplitting(s.substr(i + 1), segments_remaining - 1);
            for (auto& substr : substrings) {
                result.push_back(substr.empty() ? to_string(running_num) 
                                                : to_string(running_num) + "." + substr);
            }
            if (s[0] == '0') break; // no leading zeros
        }
        return result;
    }

    vector<string> restoreIpAddresses(string s) {
        // todo: step 1. iterate through string, keep a running integer tally
        // for digit 0 of this new integer, multiply it with 10 * 0 and add it to the tally
        // if tally is >= 0 then split this off into a new number
        // if tally is > 255, then this is invalid and we must add a period and continue
        // make the method recursive
        return recursiveIpAddressSplitting(s, 4);
    }
};
````
