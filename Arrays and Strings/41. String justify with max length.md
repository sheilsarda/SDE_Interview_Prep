# 68. Text Justification

Given an array of strings words and a width maxWidth, format the text such that each line has exactly maxWidth characters and is fully (left and right) justified.

You should pack your words in a greedy approach; that is, pack as many words as you can in each line. Pad extra spaces ' ' when necessary so that each line has exactly maxWidth characters.

Extra spaces between words should be distributed as evenly as possible. If the number of spaces on a line does not divide evenly between words, the empty slots on the left will be assigned more spaces than the slots on the right.

For the last line of text, it should be left-justified, and no extra space is inserted between words.

Note:

A word is defined as a character sequence consisting of non-space characters only.
Each word's length is guaranteed to be greater than 0 and not exceed maxWidth.
The input array words contains at least one word.
 



### Python solution

```py
class Solution:
    def fullJustify(self, words: List[str], maxWidth: int) -> List[str]:
        n = len(words)
        result = []
        words_ptr = 0

        while words_ptr < n:
            words_ptr_this_iteration = words_ptr
            line_length = 0

            while words_ptr_this_iteration < n:
                words_added_thus_far = words_ptr_this_iteration - words_ptr

                if line_length + len(words[words_ptr_this_iteration]) + (words_added_thus_far) <= maxWidth:
                    line_length += len(words[words_ptr_this_iteration])
                    words_ptr_this_iteration += 1
                else:
                    break

            gaps_between_words = words_ptr_this_iteration - words_ptr - 1
            running_string = ''

            if gaps_between_words == 0 or words_ptr_this_iteration == n:
                # only insert spaces on the right
                for word in words[words_ptr : words_ptr_this_iteration]:
                    if (running_string != ''):
                        running_string += ' '

                    running_string += word
                
                running_string += ' ' * (maxWidth - len(running_string))
                result.append(running_string)

                words_ptr = words_ptr_this_iteration
                continue

            
            spaces_required = maxWidth - line_length
            
            equal_spacing = spaces_required // gaps_between_words
            remainder = spaces_required % gaps_between_words

            for word in words[words_ptr : words_ptr_this_iteration]:
                if (running_string != ''):
                    running_string += ' ' * (equal_spacing + (1 if remainder else 0))
                    if remainder:
                        remainder -= 1

                running_string += word

            result.append(running_string)
            words_ptr = words_ptr_this_iteration
        
        return result

```
