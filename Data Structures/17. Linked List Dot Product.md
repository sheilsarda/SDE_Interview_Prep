### Sparse Vector Dot Product (Apple interview q)

Given two sparse integer arrays, implement a data structure that stores them efficiently and computes their dot product.
A sparse array is one where most of its elements are zero. Storing all elements explicitly is wasteful -- your implementation should only store non-zero elements.
Implement the LinkedList class:

LinkedList(vector<int>& nums) initializes the object with the array nums, storing only non-zero elements as (index, value) pairs in a linked list in index order
int DotProduct(const LinkedList& other) returns the dot product of the two sparse vectors

The dot product of two vectors a and b of length n is defined as:
sum(a[i] * b[i]) for i in [0, n-1]
Example 1:
Input:
nums1 = [1, 2, 0, 0, 4]
nums2 = [2, 3, 0, 5, 0]

Output: 8

Explanation: 1*2 + 2*3 + 0*0 + 0*5 + 4*0 = 2 + 6 + 0 + 0 + 0 = 8
Example 2:
Input:
nums1 = [0, 0, 0]
nums2 = [1, 2, 3]

Output: 0
Example 3:
Input:
nums1 = [1, 0, 0, 0, 1]
nums2 = [0, 0, 0, 0, 1]

Output: 1
Constraints:

1 <= nums1.length, nums2.length <= 10^5
nums1.length == nums2.length
-100 <= nums1[i], nums2[i] <= 100
At most 10^4 calls will be made to DotProduct

Follow-up: What if one vector is much sparser than the other? Does your implementation handle this efficiently?

#### CPP solution

```cpp
class LinkedListNode {
public:
    pair<int,int> value_;
    shared_ptr<LinkedListNode> next_ptr;
    LinkedListNode(pair<int,int> val, shared_ptr<LinkedListNode> next)
        : value_(val), next_ptr(next) {}
};

class LinkedList {
public:
    shared_ptr<LinkedListNode> head;

    LinkedList(const vector<int>& nums) {
        shared_ptr<LinkedListNode> last = nullptr;
        for (int i = 0; i < (int)nums.size(); i++) {
            if (nums[i] == 0) continue;
            auto node = make_shared<LinkedListNode>(make_pair(i, nums[i]), nullptr);
            if (!head) head = node;
            if (last) last->next_ptr = node;
            last = node;
        }
    }

    int DotProduct(const LinkedList& other) const {
        auto ptr_a = head;
        auto ptr_b = other.head;
        int result = 0;
        while (ptr_a && ptr_b) {
            int idx_a = ptr_a->value_.first;
            int idx_b = ptr_b->value_.first;
            if (idx_a == idx_b) {
                result += ptr_a->value_.second * ptr_b->value_.second;
                ptr_a = ptr_a->next_ptr;
                ptr_b = ptr_b->next_ptr;
            } else if (idx_a < idx_b) {
                ptr_a = ptr_a->next_ptr;
            } else {
                ptr_b = ptr_b->next_ptr;
            }
        }
        return result;
    }
};
```
