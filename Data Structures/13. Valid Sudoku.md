# 36. Valid Sudoku

Determine if a 9 x 9 Sudoku board is valid. Only the filled cells need to be validated according to the following rules:

Each row must contain the digits 1-9 without repetition.
Each column must contain the digits 1-9 without repetition.
Each of the nine 3 x 3 sub-boxes of the grid must contain the digits 1-9 without repetition.
Note:

A Sudoku board (partially filled) could be valid but is not necessarily solvable.
Only the filled cells need to be validated according to the mentioned rules.

### Python solution

```py
class Solution:
    def isValidSudoku(self, board: List[List[str]]) -> bool:
        """
        1. Each row must contain the digits 1-9 without repetition.
            Iterate through all the rows, append everything into a hashset
        2. Each column must contain the digits 1-9 without repetition.
            Iterate through all the cols, append everything into a hashset
        3. Each of the nine 3 x 3 sub-boxes of the grid must contain the digits 1-9 without repetition.
            Iterate through all sub-boxes, append everything into a hashset
        """

        uniqueRowDict = {}
        uniqueColDict = {}
        uniqueSquareDict = {}
        for rowIdx in range(9):
            uniqueRowDict[rowIdx] = set()
            uniqueColDict[rowIdx] = set()
            uniqueSquareDict[rowIdx] = set()

        for rowIdx in range(9):
            for colIdx in range(9):
                element = board[rowIdx][colIdx]
                if element == '.':
                    continue
                squareIdx = (rowIdx // 3) * 3 + (colIdx // 3)
                if int(element) in uniqueRowDict[rowIdx]:
                    return False
                if int(element) in uniqueColDict[colIdx]:
                    return False
                if int(element) in uniqueSquareDict[squareIdx]:
                    return False

                uniqueRowDict[rowIdx].add(int(element))
                uniqueColDict[colIdx].add(int(element))
                uniqueSquareDict[squareIdx].add(int(element))
        
        return True
```

### More efficient python solution

```py
class Solution(object):
    def isValidSudoku(self, board):
        res = []
        for i in range(9):
            for j in range(9):
                element = board[i][j]
                if element != '.':
                    res += [(i, element), (element, j), (i // 3, j // 3, element)]
        return len(res) == len(set(res))
```
