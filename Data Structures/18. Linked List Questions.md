## Question 1: Merge Two Sorted Sparse Vectors

### Problem

Given two sparse integer arrays stored as sorted linked lists of `(index, value)` pairs, merge them into a single sorted linked list. If both lists contain a nonzero value at the same index, sum them. If the sum is zero, omit that entry from the result.

Implement the `LinkedList` class:
- `LinkedList(vector<int>& nums)` initializes from a dense array, storing only nonzero elements
- `LinkedList merge(const LinkedList& other)` returns a new `LinkedList` representing the elementwise sum

**Example 1:**
```
Input:
nums1 = [1, 0, 3, 0, 5]
nums2 = [0, 2, -3, 0, 1]

Output: [1, 2, 0, 0, 6]
Stored as: [(0,1), (1,2), (4,6)]

Explanation:
index 0: 1 + 0 = 1
index 1: 0 + 2 = 2
index 2: 3 + -3 = 0  <- omitted
index 4: 5 + 1 = 6
```

**Example 2:**
```
Input:
nums1 = [0, 0, 0]
nums2 = [0, 0, 0]

Output: [] (empty list)
```

**Constraints:**
- `1 <= nums1.length == nums2.length <= 10^5`
- `-100 <= nums1[i], nums2[i] <= 100`

---

### Solution

```cpp
struct Node {
    int idx, val;
    shared_ptr<Node> next;
    Node(int i, int v) : idx(i), val(v), next(nullptr) {}
};

class LinkedList {
public:
    shared_ptr<Node> head;

    LinkedList() : head(nullptr) {}

    LinkedList(const vector<int>& nums) : head(nullptr) {
        shared_ptr<Node> last = nullptr;
        for (int i = 0; i < (int)nums.size(); i++) {
            if (nums[i] == 0) continue;
            auto node = make_shared<Node>(i, nums[i]);
            if (!head) head = node;
            if (last) last->next = node;
            last = node;
        }
    }

    void append(int idx, int val, shared_ptr<Node>& last) {
        auto node = make_shared<Node>(idx, val);
        if (!head) head = node;
        if (last) last->next = node;
        last = node;
    }

    LinkedList merge(const LinkedList& other) const {
        LinkedList result;
        shared_ptr<Node> last = nullptr;
        auto a = head, b = other.head;

        while (a || b) {
            int idx, val;
            if (!b || (a && a->idx < b->idx)) {
                idx = a->idx; val = a->val; a = a->next;
            } else if (!a || b->idx < a->idx) {
                idx = b->idx; val = b->val; b = b->next;
            } else {
                idx = a->idx; val = a->val + b->val;
                a = a->next; b = b->next;
            }
            if (val != 0) result.append(idx, val, last);
        }
        return result;
    }
};
```

### Explanation

This is a classic merge of two sorted sequences, identical in structure to the merge step in merge sort. The two-pointer approach walks both lists simultaneously, always consuming the node with the smaller index. When indices match, the values are summed and the entry is only appended if the sum is nonzero -- this keeps the result sparse.

The OR condition in the while loop is intentional here, unlike in dot product. Since we need to carry over remaining elements from either list (not just multiply), we cannot terminate early when one side is exhausted.

## Question 2: Linked List Running Sum Window

### Problem

Given a sparse integer array stored as a linked list of `(index, value)` pairs and a window size `k`, return a new sparse linked list where each entry is the sum of all values in the original list within the index window `[i, i+k-1]`, for every index `i` that has at least one nonzero contributor.

Implement the `SparseList` class:
- `SparseList(vector<int>& nums)` initializes from a dense array
- `SparseList windowSum(int k)` returns the windowed sum list

**Example 1:**
```
Input:
nums = [1, 0, 2, 0, 3, 0, 4]
k = 3

Output at each index:
index 0: nums[0..2] = 1+0+2 = 3
index 1: nums[1..3] = 0+2+0 = 2
index 2: nums[2..4] = 2+0+3 = 5
index 3: nums[3..5] = 0+3+0 = 3
index 4: nums[4..6] = 3+0+4 = 7

Stored as: [(0,3),(1,2),(2,5),(3,3),(4,7)]
```

**Constraints:**
- `1 <= nums.length <= 10^5`
- `1 <= k <= nums.length`
- `-100 <= nums[i] <= 100`

---

### Solution

```cpp
struct Node {
    int idx, val;
    shared_ptr<Node> next;
    Node(int i, int v) : idx(i), val(v), next(nullptr) {}
};

class SparseList {
public:
    shared_ptr<Node> head;
    int size_;

    SparseList() : head(nullptr), size_(0) {}

    SparseList(const vector<int>& nums) : size_(nums.size()), head(nullptr) {
        shared_ptr<Node> last = nullptr;
        for (int i = 0; i < (int)nums.size(); i++) {
            if (nums[i] == 0) continue;
            auto node = make_shared<Node>(i, nums[i]);
            if (!head) head = node;
            if (last) last->next = node;
            last = node;
        }
    }

    SparseList windowSum(int k) const {
        // Expand sparse list to dense for sliding window, then re-sparsify
        vector<int> dense(size_, 0);
        for (auto ptr = head; ptr; ptr = ptr->next)
            dense[ptr->idx] = ptr->val;

        // Sliding window over dense array
        int n = size_;
        vector<int> result(n - k + 1, 0);
        int window = 0;
        for (int i = 0; i < k; i++) window += dense[i];
        result[0] = window;
        for (int i = 1; i <= n - k; i++) {
            window += dense[i + k - 1] - dense[i - 1];
            result[i] = window;
        }

        return SparseList(result);
    }
};
```

### Explanation

The problem has two phases. First, expand the sparse list back to a dense array -- this is O(n) and lets you use a standard sliding window. Second, run the sliding window: maintain a running sum, adding the incoming element and subtracting the outgoing element at each step rather than recomputing the full window sum. Finally, re-sparsify the result into a new linked list.

The key insight is that sparsity helps storage but the windowed sum operation inherently touches every index in the range, so expanding to dense is not wasteful -- it just matches the problem's natural representation for this operation.

## Question 3: Intersection of Two Sparse Vectors

### Problem

Given two sparse integer arrays of possibly different lengths stored as linked lists, return a new linked list containing only the indices where **both** arrays have nonzero values, with the value being the product of the two entries at that index.

Implement the `SparseVec` class:
- `SparseVec(vector<int>& nums)` initializes from a dense array
- `SparseVec intersect(const SparseVec& other)` returns the intersection product list

**Example 1:**
```
Input:
nums1 = [1, 0, 3, 4, 0]
nums2 = [2, 3, 0, 5, 6]

Output: [(0,2), (3,20)]

Explanation:
index 0: both nonzero -> 1*2 = 2
index 1: nums1 is zero -> skip
index 2: nums2 is zero -> skip
index 3: both nonzero -> 4*5 = 20
index 4: nums1 is zero -> skip
```

**Example 2:**
```
Input:
nums1 = [0, 0, 0]
nums2 = [1, 2, 3]

Output: [] (empty)
```

**Constraints:**
- `1 <= nums1.length, nums2.length <= 10^5`
- `-100 <= nums1[i], nums2[i] <= 100`

---

### Solution

```cpp
struct Node {
    int idx, val;
    shared_ptr<Node> next;
    Node(int i, int v) : idx(i), val(v), next(nullptr) {}
};

class SparseVec {
public:
    shared_ptr<Node> head;

    SparseVec() : head(nullptr) {}

    SparseVec(const vector<int>& nums) : head(nullptr) {
        shared_ptr<Node> last = nullptr;
        for (int i = 0; i < (int)nums.size(); i++) {
            if (nums[i] == 0) continue;
            auto node = make_shared<Node>(i, nums[i]);
            if (!head) head = node;
            if (last) last->next = node;
            last = node;
        }
    }

    SparseVec intersect(const SparseVec& other) const {
        SparseVec result;
        shared_ptr<Node> last = nullptr;
        auto a = head, b = other.head;

        while (a && b) {
            if (a->idx == b->idx) {
                auto node = make_shared<Node>(a->idx, a->val * b->val);
                if (!result.head) result.head = node;
                if (last) last->next = node;
                last = node;
                a = a->next;
                b = b->next;
            } else if (a->idx < b->idx) {
                a = a->next;
            } else {
                b = b->next;
            }
        }
        return result;
    }
};
```

### Explanation

This is the AND condition in the while loop justified correctly: we only care about indices present in both lists, so the moment either pointer is exhausted, no further intersections are possible and we terminate. The two-pointer merge advances the lagging pointer whenever indices differ, which skips indices present in only one list. Only when both pointers share an index do we emit a node. This is O(nnz_a + nnz_b) time and O(min(nnz_a, nnz_b)) space for the result in the worst case.

## Question 4: Reverse a Sparse Linked List

### Problem

Given a sparse integer array of length `n` stored as a linked list of `(index, value)` pairs in ascending index order, return a new linked list that represents the array reversed. That is, the value at index `i` in the original maps to index `n-1-i` in the result.

Implement the `SparseList` class:
- `SparseList(vector<int>& nums, int n)` initializes from a dense array of length `n`
- `SparseList reverse()` returns the index-reversed list in ascending index order

**Example 1:**
```
Input:
nums = [1, 0, 0, 4, 5], n = 5

Original stored as: [(0,1), (3,4), (4,5)]

Output: [(0,5), (1,4), (4,1)]

Explanation:
index 0 <- original index 4: value 5
index 1 <- original index 3: value 4
index 4 <- original index 0: value 1
```

**Example 2:**
```
Input:
nums = [0, 2, 0, 0, 0], n = 5
Output: [(4,2)]
```

**Constraints:**
- `1 <= n <= 10^5`
- `-100 <= nums[i] <= 100`

---

### Solution

```cpp
struct Node {
    int idx, val;
    shared_ptr<Node> next;
    Node(int i, int v) : idx(i), val(v), next(nullptr) {}
};

class SparseList {
public:
    shared_ptr<Node> head;
    int n_;

    SparseList() : head(nullptr), n_(0) {}

    SparseList(const vector<int>& nums, int n) : n_(n), head(nullptr) {
        shared_ptr<Node> last = nullptr;
        for (int i = 0; i < (int)nums.size(); i++) {
            if (nums[i] == 0) continue;
            auto node = make_shared<Node>(i, nums[i]);
            if (!head) head = node;
            if (last) last->next = node;
            last = node;
        }
    }

    SparseList reverse() const {
        // Collect nodes into a vector, reverse-map indices, re-sort
        vector<pair<int,int>> entries;
        for (auto ptr = head; ptr; ptr = ptr->next)
            entries.emplace_back(n_ - 1 - ptr->idx, ptr->val);

        // Sort by new index (original was ascending, reversed is descending)
        sort(entries.begin(), entries.end());

        SparseList result;
        result.n_ = n_;
        shared_ptr<Node> last = nullptr;
        for (auto& [idx, val] : entries) {
            auto node = make_shared<Node>(idx, val);
            if (!result.head) result.head = node;
            if (last) last->next = node;
            last = node;
        }
        return result;
    }
};
```

### Explanation

Reversing the index mapping is straightforward: index `i` becomes `n-1-i`. The subtlety is that after remapping, the order of nodes flips -- the node that was last (highest index) becomes first (lowest new index). Rather than reversing the linked list in place and remapping simultaneously, it is cleaner to collect all entries into a vector, remap the indices, sort, then rebuild. The sort is O(nnz log nnz) which is fine since nnz is at most n. An alternative is to walk the original list in reverse by first reversing the pointers, but that is more error-prone with shared_ptr.

## Question 5: Linked List Sparse Matrix-Vector Multiply

### Problem

A sparse matrix is represented as a vector of `SparseRow` linked lists, where each row stores only its nonzero `(col_index, value)` pairs. Given such a matrix and a sparse vector, compute the matrix-vector product and return the result as a sparse linked list.

Implement the following:
- `SparseRow(vector<int>& row)` initializes one row from a dense array
- `SparseVec(vector<int>& nums)` initializes the input vector
- `SparseVec multiply(vector<SparseRow>& matrix, SparseVec& vec)` returns the result vector

**Example 1:**
```
Input:
matrix = [
  [1, 0, 2],   <- row 0
  [0, 3, 0],   <- row 1
  [4, 0, 5],   <- row 2
]
vec = [1, 0, 2]

Output: [5, 0, 14]
Stored as: [(0,5), (2,14)]

Explanation:
row 0 dot vec = 1*1 + 0*0 + 2*2 = 5
row 1 dot vec = 0*1 + 3*0 + 0*2 = 0  <- omitted
row 2 dot vec = 4*1 + 0*0 + 5*2 = 14
```

**Constraints:**
- Matrix is `m x n`, `1 <= m, n <= 10^3`
- `-100 <= matrix[i][j], vec[i] <= 100`

---

### Solution

```cpp
struct Node {
    int idx, val;
    shared_ptr<Node> next;
    Node(int i, int v) : idx(i), val(v), next(nullptr) {}
};

class SparseRow {
public:
    shared_ptr<Node> head;

    SparseRow(const vector<int>& row) : head(nullptr) {
        shared_ptr<Node> last = nullptr;
        for (int i = 0; i < (int)row.size(); i++) {
            if (row[i] == 0) continue;
            auto node = make_shared<Node>(i, row[i]);
            if (!head) head = node;
            if (last) last->next = node;
            last = node;
        }
    }

    int dotProduct(const SparseRow& vec) const {
        auto a = head, b = vec.head;
        int result = 0;
        while (a && b) {
            if (a->idx == b->idx) {
                result += a->val * b->val;
                a = a->next; b = b->next;
            } else if (a->idx < b->idx) {
                a = a->next;
            } else {
                b = b->next;
            }
        }
        return result;
    }
};

class SparseVec {
public:
    shared_ptr<Node> head;

    SparseVec() : head(nullptr) {}

    SparseVec(const vector<int>& nums) : head(nullptr) {
        shared_ptr<Node> last = nullptr;
        for (int i = 0; i < (int)nums.size(); i++) {
            if (nums[i] == 0) continue;
            auto node = make_shared<Node>(i, nums[i]);
            if (!head) head = node;
            if (last) last->next = node;
            last = node;
        }
    }
};

SparseVec multiply(vector<SparseRow>& matrix, SparseVec& vec) {
    // Reuse SparseRow's dotProduct by treating vec as a SparseRow
    SparseRow vec_row([]() {
        // Not directly constructible -- convert via dense representation
        return vector<int>{};
    }());

    // Build a SparseRow from the SparseVec for reuse of dotProduct
    // Share the underlying node structure
    SparseRow vec_as_row({});
    vec_as_row.head = vec.head;

    SparseVec result;
    shared_ptr<Node> last = nullptr;
    for (int i = 0; i < (int)matrix.size(); i++) {
        int val = matrix[i].dotProduct(vec_as_row);
        if (val == 0) continue;
        auto node = make_shared<Node>(i, val);
        if (!result.head) result.head = node;
        if (last) last->next = node;
        last = node;
    }
    return result;
}
```

### Explanation

Each entry in the output vector is the dot product of one row of the matrix with the input vector. Since both the row and the input vector are stored as sorted sparse linked lists, the dot product reuses the same two-pointer merge from Question 1 -- advance the lagging pointer, multiply when indices match.

The outer loop iterates over rows, computing one dot product per row and only emitting a result node if the value is nonzero. Total complexity is O(m * (nnz_row + nnz_vec)) where nnz_row is the average nonzeros per row. For a truly sparse matrix this is far cheaper than the dense O(m*n) multiply. The trick of aliasing `vec` as a `SparseRow` by sharing the head pointer avoids duplicating node storage -- both `SparseRow` and `SparseVec` use the same `Node` type so the pointer is directly reusable.
